sovok

AI desktop companion for Windows. Chat with a protogen buddy in a side panel; every few minutes it peeks at your screen and asks what you're up to. Works with Claude or any OpenAI-compatible API (bring your own key). Send it images, PDFs and code files too.

Corner mode: it sits on your screen and talks in a speech bubble. Click it or press Ctrl+Shift+Space to text it, drag it to move it, right-click for more.

changed co-op

Online co-op for Changed (Steam), 2+ players. The host plays the real game; friends join the same world with their own character. Enemies chase the nearest player, caught players become latex ghosts a teammate can revive, and it's game over only when everyone is caught. Connects through a relay, so no port forwarding.

irm https://tool.dexx.moe/install-changed-coop.ps1 | iex

In game: title screen → CO-OP. Host: Host game, then share your room code. Friends: type the room code → Join game. Everyone needs the same version.

Uninstall: $coopUninstall=1; irm https://tool.dexx.moe/install-changed-coop.ps1 | iex
